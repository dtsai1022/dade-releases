# DAD-E downloads

Windows installers and update files for DAD-E.

- Download the newest installer from the [latest release](../../releases/latest).
- The installers are not code-signed yet, so Windows shows a "Windows protected your PC" notice the first time. Choose **More info**, then **Run anyway**.
- DAD-E checks this page for a newer version and only downloads or installs it when you click.

This repository holds downloads only; it contains no source code.
